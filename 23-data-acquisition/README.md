# Data Acquisition Skills

This category contains skills for acquiring data from various sources for analysis workflows.

## Skills in This Category

### 1. querying-sql-databases
Working with SQL databases using pandas and SQLAlchemy.

**Key Features**:
- Connection pooling and management
- Parameterized queries for security
- Query optimization techniques
- Pagination and chunking for large datasets
- Support for PostgreSQL, MySQL, SQLite, SQL Server

**When to Use**: Extracting data from relational databases for analysis

### 2. web-scraping
Extracting data from websites using BeautifulSoup, Scrapy, and Selenium.

**Key Features**:
- HTML parsing with CSS selectors and XPath
- Dynamic content handling with JavaScript rendering
- Large-scale crawling with Scrapy
- Anti-bot countermeasures
- Ethical scraping guidelines

**When to Use**: Collecting data from websites when no API is available

### 3. api-integration
Integrating with REST APIs using requests and httpx.

**Key Features**:
- Multiple authentication methods (API keys, OAuth 2.0, JWT)
- Pagination handling (offset, page, cursor-based)
- Rate limiting and retry logic
- Async requests for performance
- GraphQL support

**When to Use**: Fetching data from web services and APIs
